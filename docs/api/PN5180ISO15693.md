# `PN5180ISO15693`

`#include <PN5180ISO15693.h>`

ISO 15693 (NFC-V) support, including NXP ICODE SLIX / SLIX2 specific commands. Inherits everything from [`PN5180`](PN5180.md).

UIDs are 8 bytes, stored **least significant byte first** (`uid[7]` is the most significant byte, usually `0xE0`).

### `PN5180ISO15693(uint8_t SSpin, uint8_t BUSYpin, uint8_t RSTpin, SPIClass& spi = SPI)`

Same as the [`PN5180` constructor](PN5180.md#setup).

### `bool setupRF()`

Loads the ISO 15693 RF configuration and switches the field on. Call it after `reset()`.

## Inventory

| Method | Description |
|--------|-------------|
| `getInventory(uint8_t *uid)` | Read the UID of one tag into an 8-byte buffer |
| `getInventoryMultiple(uint8_t *uid, uint8_t maxTags, uint8_t *numCard)` | Read the UIDs of up to `maxTags` tags (anti-collision). `uid` must hold `8 * maxTags` bytes. UID *n* is at `uid[8*n]`. `numCard` returns how many were found. Stops once `maxTags` UIDs are stored. Each UID is reported once. Returns `ISO15693_EC_OK` even if some tags could not be resolved (see below) |

**How `getInventoryMultiple()` resolves collisions:** each tag answers in one of 16 time slots, picked by 4 bits of its UID. When several tags answer in the same slot, that slot is polled again with a longer mask (4 more UID bits), until no collided slots are left. The search is bounded: at most 16 collided slots waiting at once, masks up to 32 UID bits, and 64 rounds per call. Tags beyond those limits are not reported. A tag whose answer is received cleanly while another tag answered in the same slot may hide the other one; call it again if you expect more tags.

> **Hardware note:** RF coupling limits how many tags can be read at once. On a small PN5180 module antenna, two full-size ISO 15693 cards stacked flat blocked each other completely; with one sheet of paper between them both read reliably, and adding a third card made one of the others drop out. Small tags (stickers, coin tags) couple far less.

## Memory

Call `getSystemInfo()` first to learn the tag's block size and block count.

| Method | Description |
|--------|-------------|
| `getSystemInfo(uint8_t *uid, uint8_t *blockSize, uint8_t *numBlocks)` | Read the memory layout of the tag with this UID. `blockSize` and `numBlocks` are only written if the tag reports its memory size; initialize them first |
| `readSingleBlock(const uint8_t *uid, uint8_t blockNo, uint8_t *blockData, uint8_t blockSize)` | Read one block |
| `writeSingleBlock(const uint8_t *uid, uint8_t blockNo, const uint8_t *blockData, uint8_t blockSize)` | Write one block |
| `readMultipleBlock(const uint8_t *uid, uint8_t blockNo, uint8_t numBlock, uint8_t *blockData, uint8_t blockSize)` | Read `numBlock` blocks starting at `blockNo`. `blockData` must hold `numBlock * blockSize` bytes |

`readMultipleBlock()` returns `ISO15693_EC_BLOCK_NOT_AVAILABLE` without contacting the tag if `numBlock` is 0, the range runs past block 255, or `numBlock * blockSize` exceeds 507 bytes. Blocks the tag doesn't have are normally reported by the tag itself, often as `ISO15693_EC_UNKNOWN_ERROR` (0x0F). Some tags instead return only the blocks they have, without an error. `readMultipleBlock()` then returns `ISO15693_EC_BLOCK_NOT_AVAILABLE` and the contents of `blockData` are undefined.

If a tag's answer is shorter than the requested data, `readSingleBlock()`, `getInventory()`, `getSystemInfo()` and `getRandomNumber()` return `ISO15693_EC_UNKNOWN_ERROR` instead of filling the output from stale buffer contents. For `getSystemInfo()` this includes an answer shorter than the optional fields its info flags announce.

> **Known issue:** `numBlocks` is a `uint8_t`, so a tag with 256 blocks reports `numBlocks` = 0.

## ICODE SLIX2 privacy and passwords

See the [SLIX2 datasheet](../../extras/SL2S2602.pdf) for the password identifiers and privacy behavior. Passwords are 4 bytes.

| Method | Description |
|--------|-------------|
| `getRandomNumber(uint8_t *randomData)` | Get the 2-byte random number needed by password commands |
| `setPassword(uint8_t identifier, const uint8_t *password, const uint8_t *random)` | Send a password (XOR'd with the random number) |
| `enablePrivacy(const uint8_t *password, const uint8_t *random)` | Put the tag into privacy mode |
| `enablePrivacyMode(const uint8_t *password)` | Helper: random number + enable privacy in one call |
| `disablePrivacyMode(const uint8_t *password)` | Helper: random number + privacy password to leave privacy mode |

## Error codes

Every method except `setupRF()` returns an `ISO15693ErrorCode`. `strerror(code)` returns a readable message.

| Code | Value | Meaning |
|------|-------|---------|
| `ISO15693_EC_OK` | `0x00` | Success |
| `EC_NO_CARD` | `-1` | No tag answered (library code) |
| `ISO15693_EC_NOT_SUPPORTED` | `0x01` | Command not supported |
| `ISO15693_EC_NOT_RECOGNIZED` | `0x02` | Command not recognized |
| `ISO15693_EC_OPTION_NOT_SUPPORTED` | `0x03` | Option not supported |
| `ISO15693_EC_UNKNOWN_ERROR` | `0x0F` | Unknown error |
| `ISO15693_EC_BLOCK_NOT_AVAILABLE` | `0x10` | Block does not exist |
| `ISO15693_EC_BLOCK_ALREADY_LOCKED` | `0x11` | Block already locked |
| `ISO15693_EC_BLOCK_IS_LOCKED` | `0x12` | Block is locked; cannot change it |
| `ISO15693_EC_BLOCK_NOT_PROGRAMMED` | `0x13` | Block programming failed |
| `ISO15693_EC_BLOCK_NOT_LOCKED` | `0x14` | Block locking failed |
| `ISO15693_EC_CUSTOM_CMD_ERROR` | `0xA0` | Error in a custom (SLIX2) command |

Codes other than `EC_NO_CARD` come from the tag itself.
