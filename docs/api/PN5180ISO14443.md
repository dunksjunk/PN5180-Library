# `PN5180ISO14443`

`#include <PN5180ISO14443.h>`

ISO 14443 Type A support: MIFARE Classic, MIFARE Ultralight, NTAG. Inherits everything from [`PN5180`](PN5180.md).

### `PN5180ISO14443(uint8_t SSpin, uint8_t BUSYpin, uint8_t RSTpin, SPIClass& spi = SPI)`

Same as the [`PN5180` constructor](PN5180.md#setup).

### `bool setupRF()`

Loads the ISO 14443A RF configuration and switches the field on. Call it after `reset()`.

## Card detection

### `bool isCardPresent()`

Returns `true` if a card with a valid UID is in the field. Internally this runs a full `readCardSerial()`, including the field reset. Calling `readCardSerial()` right after it works but activates the card a second time. To save the extra round trip, call `readCardSerial()` alone and check for `> 0`.

### `int8_t readCardSerial(uint8_t *buffer)`

Activates a card and copies its UID into `buffer`. Pass a buffer of at least 10 bytes.

Each call first switches the RF field off for 10 ms. That resets every card in the field to IDLE, so the card answers again even if a previous call left it active or `mifareHalt()` halted it. Any MIFARE Classic authentication is lost. Read blocks *after* `readCardSerial()`, not across calls. A call with a card takes about 160 ms (measured on ESP32 with an NTAG215).

Returns:

| Value | Meaning |
|-------|---------|
| `4` or `7` | UID length in bytes |
| `0` | The card returned an invalid UID |
| `-1` | No card answered, or the SPI exchange with the PN5180 failed |
| `-2` | Card in field, but the exchange failed |

Only a positive value means `buffer` holds a UID. Test `> 0`, not `!= 0` or truthiness.

10-byte (triple-size) UIDs are not supported yet.

### `int8_t activateTypeA(uint8_t *buffer, uint8_t kind)`

Low-level card activation. `kind` is `0` to send REQA (only idle cards answer) or `1` to send WUPA (halted cards answer too). On success, `buffer` (10 bytes) holds:

| Offset | Content |
|--------|---------|
| 0–1 | ATQA |
| 2 | SAK |
| 3–9 | UID (4 bytes at 3–6, or 7 bytes at 3–9) |

Returns the UID length, or the same `0` / `-1` / `-2` values as `readCardSerial()`.

## MIFARE Classic / Ultralight

Authenticate first with [`mifareAuthenticate()`](PN5180.md#mifare-classic-authentication) for MIFARE Classic.

| Method | Description |
|--------|-------------|
| `bool mifareBlockRead(uint8_t blockno, uint8_t *buffer)` | Read 16 bytes starting at `blockno` into `buffer`. Returns `true` if 16 bytes came back |
| `uint8_t mifareBlockWrite16(uint8_t blockno, const uint8_t *buffer)` | Write 16 bytes to `blockno`. Returns the card's ACK/NAK byte (`0x0A` = ACK), or `0` if the SPI exchange failed |
| `bool mifareHalt()` | Put the card into HALT state. It will then answer only WUPA (`activateTypeA(buf, 1)`) |
