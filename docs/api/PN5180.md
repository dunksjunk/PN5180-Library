# `PN5180` (base class)

`#include <PN5180.h>`

Wraps the PN5180 host-interface commands. Every command goes over SPI with the BUSY-line handshake from the datasheet. Each wait is bounded by [`commandTimeout`](#commandtimeout).

## Setup

### `PN5180(uint8_t SSpin, uint8_t BUSYpin, uint8_t RSTpin, SPIClass& spi = SPI)`

Constructor. `SSpin` is NSS (chip select). Pass another `SPIClass` to use a second SPI bus (for example `HSPI` on ESP32).

### `void begin(int8_t sck = -1, int8_t miso = -1, int8_t mosi = -1, int8_t SSpin = -1)`

Configures the pins and starts SPI. Call it once in `setup()` before anything else.
On ESP32, if `sck`, `miso` and `mosi` are all given, SPI starts on those pins. Otherwise, and on all other boards, the board's default SPI pins are used. `SSpin` overrides the NSS pin from the constructor.

### `void end()`

Stops SPI.

### `void setSPISettingsFrecuency(uint32_t frecuency)`

Sets the SPI clock in Hz (default 7 MHz). Lower it for long wires. The misspelling is part of the public API and is kept for compatibility.

### `void reset()`

Pulses RST and waits for the PN5180 to finish starting up (bounded by `commandTimeout`).

### `commandTimeout`

`uint16_t commandTimeout = 500;`

Public member: the maximum time in milliseconds to wait for the BUSY line during a command. While waiting, the library calls `delay(1)`, so other FreeRTOS tasks keep running on ESP32.

## Registers

| Method | Description |
|--------|-------------|
| `bool writeRegister(uint8_t reg, uint32_t value)` | Write a 32-bit register |
| `bool writeRegisterWithOrMask(uint8_t addr, uint32_t mask)` | `reg |= mask` |
| `bool writeRegisterWithAndMask(uint8_t addr, uint32_t mask)` | `reg &= mask` |
| `bool readRegister(uint8_t reg, uint32_t *value)` | Read a 32-bit register |

Register addresses are defined in `PN5180.h`: `SYSTEM_CONFIG`, `IRQ_ENABLE`, `IRQ_STATUS`, `IRQ_CLEAR`, `TRANSCEIVE_CONTROL`, `TIMER1_RELOAD`, `TIMER1_CONFIG`, `RX_WAIT_CONFIG`, `CRC_RX_CONFIG`, `RX_STATUS`, `TX_WAIT_CONFIG`, `TX_CONFIG`, `CRC_TX_CONFIG`, `RF_STATUS`, `SYSTEM_STATUS`, `TEMP_CONTROL`, `AGC_REF_CONFIG`. See the [datasheet](../../extras/PN5180A0XX_C3_C4.pdf) for the bits.

## EEPROM

| Method | Description |
|--------|-------------|
| `bool readEEprom(uint8_t addr, uint8_t *buffer, int len)` | Read `len` bytes starting at `addr` |
| `bool writeEEprom(uint8_t addr, const uint8_t *buffer, uint8_t len)` | Write `len` bytes starting at `addr` |

Useful addresses: `DIE_IDENTIFIER`, `PRODUCT_VERSION`, `FIRMWARE_VERSION`, `EEPROM_VERSION` (2 bytes each, minor then major), `IRQ_PIN_CONFIG`, and the LPCD settings `LPCD_REFERENCE_VALUE`, `LPCD_FIELD_ON_TIME`, `LPCD_THRESHOLD`, `LPCD_REFVAL_GPO_CONTROL`.

> Writing the EEPROM changes the chip's power-on configuration permanently. Read the datasheet first.

## RF field and configuration

| Method | Description |
|--------|-------------|
| `bool loadRFConfig(uint8_t txConf, uint8_t rxConf)` | Load a protocol RF configuration (ISO 14443A: `0x00`/`0x80`, ISO 15693: `0x0D`/`0x8D`). Normally done for you by `setupRF()` |
| `bool setRF_on()` | Switch the RF field on |
| `bool setRF_off()` | Switch the RF field off |

## Raw RF data

| Method | Description |
|--------|-------------|
| `bool sendData(const uint8_t *data, int len, uint8_t validBits = 0)` | Transmit `len` bytes. `validBits` is the number of valid bits in the last byte (0 = all 8) |
| `bool readData(int len, uint8_t *buffer)` | Read `len` received bytes (max 508) into your buffer |
| `uint8_t *readData(int len)` | Read `len` received bytes (max 508) into a **library-owned** buffer and return a pointer to it, or `NULL` if `len` is out of range or the buffer can't be allocated |

The pointer from `readData(len)` is only valid until the next `readData` call. Copy the data out before sending another command. Up to 16 bytes use a small static buffer. Longer reads use a 508-byte buffer that is allocated on first use and kept for the object's lifetime.

## Interrupt and transceive state

| Method | Description |
|--------|-------------|
| `uint32_t getIRQStatus()` | Read `IRQ_STATUS`. Bits: `RX_IRQ_STAT`, `TX_IRQ_STAT`, `IDLE_IRQ_STAT`, `RFOFF_DET_IRQ_STAT`, `RFON_DET_IRQ_STAT`, `TX_RFOFF_IRQ_STAT`, `TX_RFON_IRQ_STAT`, `RX_SOF_DET_IRQ_STAT`, `GENERAL_ERROR_IRQ_STAT`, `LPCD_IRQ_STAT` |
| `bool clearIRQStatus(uint32_t irqMask)` | Clear the given IRQ bits (`0xFFFFFFFF` clears all) |
| `PN5180TransceiveStat getTransceiveState()` | Current transceiver state: `PN5180_TS_Idle`, `_WaitTransmit`, `_Transmitting`, `_WaitReceive`, `_WaitForData`, `_Receiving`, `_LoopBack`, `_RESERVED` |

## Low Power Card Detection (LPCD)

| Method | Description |
|--------|-------------|
| `bool prepareLPCD()` | Store the LPCD settings (field-on time, threshold, self-calibration mode, GPO control) in EEPROM. Only bytes that differ are written, so it is safe to call on every boot or wake-up. Returns `false` if an EEPROM read, write or read-back check fails |
| `bool switchToLPCD(uint16_t wakeupCounterInMs)` | Enter LPCD. The PN5180 checks for a card every `wakeupCounterInMs` ms and raises IRQ (`LPCD_IRQ_STAT`) when it detects one |

See the [LPCD examples](../examples.md) for a complete flow, including ESP32 deep sleep.

## MIFARE Classic authentication

### `int16_t mifareAuthenticate(uint8_t blockno, const uint8_t *key, uint8_t keyType, const uint8_t *uid)`

Authenticates a sector of an activated MIFARE Classic card.

- `key`: 6-byte key
- `keyType`: `MIFARE_CLASSIC_KEYA` (`0x60`) or `MIFARE_CLASSIC_KEYB` (`0x61`)
- `uid`: 4-byte UID

Returns `0` when authenticated, the PN5180's non-zero status byte when authentication fails, `-2` for an invalid `keyType`, and `-3` if the SPI transaction failed.

## Low-level command access

### `bool sendCommand(uint8_t *sendBuffer, size_t sendBufferLen, uint8_t *recvBuffer, size_t recvBufferLen)`

Sends a raw host-interface command (first byte is the command code) and optionally reads a response. Use it for PN5180 commands the library does not wrap.
